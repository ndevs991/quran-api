Akses data surah, ayat, terjemahan, dan audio murottal melalui REST API.

Murottal Player

Dengarkan murottal per surah, lihat teks ayat, terjemahan, dan tafsir langsung dari browser.

Buka Murottal Player →

Base URL

https://quran-api-991.vercel.app/

Endpoints

GET/surahs GET/surahs/{number} GET/surahs/{number}/audio GET/ayahs/{surah}/{ayah} GET/search?q= GET/juz/{number} GET/random GET/qoriahs GET/qoriahs/{identifier}/surahs/{number}

Get All Surahs

Mengambil daftar nomor dan nama seluruh surah Al-Qur'an.

GET/surahs

Get Surah

Mengambil data surah berdasarkan nomor.

GET/surahs/{number}

Surah Audio

Mengambil audio full 1 surah berdasarkan qori (default: Alafasy).

GET/surahs/{number}/audio

Get Ayah

Mengambil 1 ayat spesifik langsung tanpa mengambil seluruh surah.

GET/ayahs/{surah}/{ayah}

Search

Mencari ayat berdasarkan kata kunci (arab atau terjemahan).

GET/search?q=

Get Juz

Mengambil seluruh ayat berdasarkan nomor juz (1-30).

GET/juz/{number}

Random Ayah

Mengambil ayat Al-Qur'an secara acak. Bisa dibatasi ke surah tertentu dengan parameter ?surah=.

GET/random

Surah Audio by Qori

Mengambil audio full 1 surah berdasarkan identifier qori tertentu.

GET/qoriahs/{identifier}/surahs/{number}

Widget Ayat

Tempel satu ayat lengkap dengan teks Arab, terjemahan, dan tombol putar ke situs apa pun, misalnya blog, situs masjid, atau sekolah. Cukup dua baris kode:

<script src="https://quran-api-991.vercel.app/widget.js" async></script>
    <div class="quran-ayah" data-surah="2" data-ayah="255"></div>

Hasilnya:

Tombol 🔀 di kiri tombol play menampilkan ayat acak/random. Muat ulang halaman mengembalikan widget ke ayat yang ditempel.

AtributKeterangan
data-surah Nomor surah (1-114). Wajib.
data-ayah Nomor ayat. Wajib.
data-theme light (default) atau dark.
data-qori Qori untuk tombol putar: ar.alafasy (default), ar.ahmedajamy, ar.husarymujawwad, ar.minshawi, ar.muhammadayyoub, ar.muhammadjibreel.

Tidak perlu menulis kode sendiri: buka Murottal Player, klik ⋮ pada ayat yang diinginkan, lalu pilih Sematkan Ayat untuk mendapat kode siap salin.

Tentang Quran API

Quran API adalah layanan REST API untuk mengakses data Al-Qur'an dalam format JSON. API ini dapat digunakan oleh pengembang untuk membuat website, aplikasi mobile, platform pembelajaran Islam, dan berbagai proyek digital yang membutuhkan data Al-Qur'an. Dengan format respons yang terstruktur, data dapat diolah menggunakan JavaScript, PHP, maupun bahasa pemrograman lain yang mendukung permintaan HTTP.

Melalui endpoint yang tersedia, pengembang dapat mengintegrasikan informasi surah, ayat, terjemahan, serta audio murottal sesuai dukungan masing-masing endpoint. Quran API juga menyediakan dokumentasi penggunaan agar pengembang dapat memahami alamat endpoint, parameter permintaan, dan struktur respons sebelum mengintegrasikannya ke dalam aplikasi.

Fitur Quran API

Data Surah Al-Qur'an

Data surah dapat digunakan untuk membuat daftar surah, halaman informasi surah, dan navigasi bacaan Al-Qur'an. Aplikasi dapat memanfaatkan informasi yang dikembalikan API untuk menampilkan daftar surah sehingga pengguna dapat memilih surah yang ingin dibaca. Fitur ini berguna untuk website Al-Qur'an digital, aplikasi pendidikan, maupun proyek pribadi yang membutuhkan struktur data surah.

Teks Ayat dan Terjemahan

Data ayat memungkinkan pengembang menampilkan teks Arab Al-Qur'an beserta terjemahan yang tersedia. Informasi tersebut dapat disusun menjadi halaman bacaan yang mudah digunakan pada perangkat desktop maupun ponsel. Pengembang juga dapat mengatur ukuran tulisan Arab, jarak antarbaris, warna teks, dan tata letak terjemahan sesuai kebutuhan desain aplikasi.

Audio Murottal Berbagai Qori

Audio murottal dapat digunakan untuk menambahkan pengalaman mendengarkan bacaan Al-Qur'an ke dalam website atau aplikasi. Pengembang dapat membuat pemutar audio dengan kontrol putar, jeda, dan navigasi surah sesuai fitur yang didukung oleh implementasi mereka. Ketersediaan audio bergantung pada qori dan surah yang tersedia pada sumber data masing-masing.

Pencarian Ayat

Endpoint pencarian dapat membantu pengguna menemukan data berdasarkan kata kunci dan parameter yang didukung. Fitur pencarian dapat dikembangkan menjadi fasilitas pencarian pada website Al-Qur'an, halaman referensi ayat, atau aplikasi pembelajaran. Untuk mendapatkan hasil yang sesuai, pengembang perlu mengikuti format parameter pencarian yang dijelaskan dalam dokumentasi endpoint.

Data Juz dan Ayat Acak

Informasi juz dapat dimanfaatkan untuk membuat navigasi bacaan berdasarkan pembagian juz Al-Qur'an. Sementara itu, fitur ayat acak dapat digunakan untuk menampilkan ayat pilihan pada halaman utama, widget harian, atau bagian inspirasi pada website. Pastikan penggunaan masing-masing fitur mengikuti endpoint dan format respons yang tersedia pada dokumentasi.

Cara Menggunakan Quran API

Untuk mulai menggunakan Quran API, buka bagian Base URL dan Endpoints pada halaman dokumentasi ini. Pilih endpoint sesuai data yang dibutuhkan, lalu periksa contoh URL, parameter, dan respons JSON yang dihasilkan. Pengujian awal melalui browser dapat membantu memahami struktur data sebelum endpoint digunakan di dalam kode aplikasi.

Integrasi dengan JavaScript

JavaScript dapat mengambil data API menggunakan fungsi fetch(). Setelah respons berhasil diterima, data JSON dapat diolah untuk membuat daftar surah, menampilkan ayat, atau memperbarui konten halaman secara dinamis. Pengembang sebaiknya menangani kondisi ketika permintaan gagal, respons tidak sesuai harapan, atau data yang dibutuhkan tidak tersedia.

Integrasi dengan PHP

Aplikasi PHP dapat mengirim permintaan HTTP ke endpoint API, membaca respons JSON, kemudian mengolahnya untuk ditampilkan pada halaman website. Pendekatan ini dapat digunakan pada website yang menggunakan PHP sebagai bahasa pemrograman server. Pastikan respons API diperiksa sebelum digunakan dan data yang ditampilkan di halaman HTML ditangani dengan benar.

Widget Ayat Al-Qur'an

Widget Ayat memungkinkan pemilik website menampilkan ayat Al-Qur'an pada halaman mereka melalui elemen HTML yang disediakan. Fitur ini dapat berguna untuk blog pribadi, website masjid, sekolah, lembaga pendidikan Islam, dan komunitas Muslim yang ingin menyertakan ayat dalam konten mereka.

Pengembang dapat menentukan surah dan ayat melalui atribut widget sesuai dokumentasi yang tersedia. Jika didukung oleh implementasi widget, tampilan dapat mencakup teks Arab, terjemahan, serta kontrol untuk memutar audio. Periksa bagian Widget Ayat di halaman ini untuk melihat contoh kode pemasangan dan atribut yang dapat digunakan.

Cara Memasang Widget

Salin kode widget dari bagian dokumentasi, kemudian tempatkan elemen HTML pada posisi halaman tempat ayat ingin ditampilkan. Pastikan file JavaScript widget dapat diakses oleh browser dan atribut surah serta ayat diisi dengan nilai yang sesuai. Setelah dipasang, buka halaman website untuk memeriksa apakah widget tampil dan berfungsi sebagaimana mestinya.

Penggunaan Quran API untuk Berbagai Proyek

Quran API dapat dimanfaatkan sebagai sumber data untuk beragam proyek digital, seperti website bacaan Al-Qur'an, aplikasi pembelajaran, pemutar audio murottal, dan halaman referensi ayat. Data yang tersedia dapat diintegrasikan dengan antarmuka buatan sendiri sehingga pengembang memiliki keleluasaan dalam menentukan tampilan dan alur penggunaan aplikasi.

Untuk proyek pendidikan, data ayat dan terjemahan dapat digunakan sebagai bagian dari materi belajar. Untuk website komunitas, widget ayat dapat membantu menampilkan konten Al-Qur'an tanpa harus membangun seluruh komponen dari awal. Sementara itu, aplikasi yang berfokus pada audio dapat menggunakan informasi murottal sesuai ketersediaan sumber audio yang didukung.

Dokumentasi dan Panduan Pengembang

Sebelum mengintegrasikan API ke dalam proyek, pelajari Base URL, daftar Endpoints, dan contoh respons yang tersedia pada halaman ini. Perhatikan parameter yang wajib dikirim, struktur JSON yang dikembalikan, serta kemungkinan kondisi ketika data tidak ditemukan. Pengujian endpoint secara terpisah akan membantu proses integrasi dan memudahkan penelusuran kesalahan.

Pengembang juga disarankan untuk menangani kegagalan jaringan, memeriksa status respons, dan menampilkan pesan yang informatif ketika data tidak dapat dimuat. Jika aplikasi menampilkan teks Arab, pastikan halaman menggunakan encoding UTF-8 dan memilih font yang mendukung karakter Arab. Pengaturan tata letak dari kanan ke kiri dapat digunakan jika sesuai dengan desain halaman.

Mulai Integrasi Quran API

Gunakan contoh endpoint dan kode yang tersedia pada dokumentasi sebagai titik awal pengembangan. Pilih hanya fitur yang diperlukan oleh proyek, lalu sesuaikan pemrosesan data dan tampilan dengan kebutuhan pengguna. Dengan memahami struktur respons dan batasan setiap endpoint, pengembang dapat membangun pengalaman membaca, mencari, dan mendengarkan Al-Qur'an yang sesuai dengan tujuan website atau aplikasi mereka.
