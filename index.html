Quotes API

REST API untuk mengakses kutipan (quotes) dan penulisnya.

1. Random Quote

GET https://quotes-api-991.vercel.app/api/quotes 
{
  "key": "pramoedya_ananta_toer",
  "quote": "Kemudian malam melanjutkan tugasnya: kosong dari segala perasaan.",
  "author": "Pramoedya Ananta Toer"
}

2. Quote by Key

GET https://quotes-api-991.vercel.app/api/quotes?key=key_quote 
[
  {
    "key": "pramoedya_ananta_toer",
    "quote": "Masa terbaik dalam hidup seseorang adalah masa ia dapat menggunakan kebebasan yang telah direbutnya sendiri.",
    "author": "Pramoedya Ananta Toer"
  }
]

3. List Authors

GET https://quotes-api-991.vercel.app/api/quotes?listAuthors=true 
{
  "pramoedya_ananta_toer": ["Pramoedya Ananta Toer"],
  "another_key": ["Author Name"]
}
