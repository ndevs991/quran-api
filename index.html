Quran API

REST API untuk mengakses data Al-Qur'an dan qari.

Endpoints

GET/surahs GET/surahs/{number} GET/random GET/qoriahs

Get All Surahs

Mengambil daftar nomor dan nama seluruh surah Al-Qur'an.

GET/surahs

Get Surah

Mengambil data surah berdasarkan nomor.

GET/surahs/1

Random Ayah

Mengambil ayat Al-Qur'an secara acak.

GET/random

Qoriah

Mengambil daftar qari yang tersedia.

GET/qoriahs

    {
